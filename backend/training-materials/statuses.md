# Status Meanings

Statuses mark where the ticket is in its resolution process.

## Open

This is the default status of tickets before they are assigned. At this point, the ticket can be claimed freely.

## In Progress

This is the status after a ticket is assigned or claimed. It denotes that the ticket is in the process of resolution but requires no user intervention. It should not be used when the user needs to reply to a comment.

## Waiting For Response

This status should be used only when the user needs to do or say something. If an agent asks a question, the ticket should be marked as Waiting For Response until a reply is received.

Once the user replies, the ticket can either be moved back to In Progress or forward to Resolved.

If a ticket is completed on the agent's side, it should be moved to this status until the user confirms that their request is satisfied.

## Resolved

When this status is reached, agents can no longer forfeit the ticket, nor can they move the status backwards. Their only options are to comment and to close the ticket.

This status is used for sending final messages to users. For example, if users are to rate their experience, the survey should be sent during this Status. After the agent is finished, the ticket should be closed.

## Closed

Closed tickets cannot be commented on, claimed, or otherwise edited.
